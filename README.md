🐱 Cat Article Catalog

Адаптивний сайт-каталог з картками статей про котів. Реалізовано на чистому HTML, CSS та JavaScript, без сторонніх бібліотек.

⸻

🔧 Функціональність
 • Адаптивна верстка для мобільних і десктопів.
 • Картки статей з:
 • зображенням;
 • заголовком;
 • коротким описом;
 • кнопкою переходу.
 • Пагінація (розбивка на сторінки).
 • Sticky-навігація.
 • Бургер-меню для мобільної версії (виїжджає збоку).
 • Дані про статті зберігаються у файлі dummyData.js.

⸻
